# BG Matte 오프라인 팩 (인터넷 없이 설치)

인터넷이 안 되는 PC(촬영 현장 노트북, 보안망 PC 등)에도 BG Matte를 설치할 수 있게, **설치에 필요한 모든 파일을 한 덩어리로 묶은 폴더(또는 zip)** 입니다.
팩을 한 번 만들어 두면 USB로 옮기기만 하면 되고, 설치하는 PC는 인터넷에 접속하지 않습니다.

## 기존 설치 방식과 차이

| | 기존 `install_windows.bat` / Setup.exe | 오프라인 팩 |
|---|---|---|
| 설치 시 인터넷 | 필요 (파이썬 환경, PyTorch, 엔진 코드, 가중치를 받음) | **필요 없음** |
| 용량 | 작음 (수십 MB) | 큼 (약 3.5GB, GPU 버전 1종 기준) |
| 파이썬 | Miniforge(conda)를 찾거나 설치 | 팩 안의 파이썬 3.11을 `C:\BGMatte\python`에 설치 (conda 불필요) |
| 설치 위치 | `C:\BGMatte\app` (Setup.exe) 또는 압축 푼 폴더 | `C:\BGMatte\app` 고정 |

## 1단계: 팩 만들기 (인터넷 되는 윈도우 PC에서 한 번)

1. 이 저장소를 zip으로 받아 풀거나 최신 소스 폴더를 준비합니다. 파이썬 3.8 이상이 있으면 됩니다 (이 PC에 앱이 설치되어 있다면 그 파이썬을 쓰면 됩니다).
2. 터미널에서:

```
python packaging\build_offline_pack.py
```

- 기본은 **CUDA 12.6** 용 PyTorch를 담습니다. NVIDIA GPU가 없는 PC에서도 같은 파일이 CPU로 동작하므로 PC 종류별로 따로 만들 필요가 없습니다.
- RTX 50 시리즈처럼 아주 최신 GPU가 있는 PC가 섞여 있으면 `--cuda cu128` 을 쓰거나, `--cuda cu126 --cuda cu128` 처럼 둘 다 담습니다 (용량이 약 2배가 됩니다).
- 받는 도중 끊기면 같은 명령을 다시 실행하세요. 이미 받은 것은 건너뜁니다.
- 끝나면 `dist\BGMatte_Offline_v<버전>\` 폴더와 같은 이름의 `.zip` 이 생깁니다. 폴더가 필요 없으면 `--no-zip`, zip만 필요하면 폴더는 지워도 됩니다.

팩 안에는 파이썬 설치 파일, PyTorch·앱 라이브러리 wheel, 엔진 코드 2종, 가중치 5종, 앱이 들어 있고, 마지막에 **받은 파일만으로 설치가 되는지 자동 검증**을 합니다 (빠진 의존 패키지가 있으면 여기서 실패로 알려 줍니다).

## 2단계: 설치할 PC에서

1. 팩을 USB나 공유 폴더로 옮깁니다. zip이면 **반드시 '모두 압축 풀기'** 를 한 뒤 사용하세요 (압축 파일 안에서 바로 실행하면 안 됩니다).
2. 풀린 폴더의 `install_offline.bat` 을 더블클릭합니다. 약 10분 뒤 바탕화면에 `BG Matte` 바로가기가 생깁니다.
3. 설치가 끝나면 마지막 메시지에 "엔진 코드 2종과 가중치 5종이 모두 이 PC에 있습니다"가 나옵니다.

다시 실행하면 새 버전으로 덮어씁니다. 설정과 촬영해 둔 빈 배경은 유지됩니다.

## 문제가 생기면

| 증상 | 원인 / 해결 |
|---|---|
| "offline 폴더를 찾지 못했습니다" | zip을 풀지 않고 실행했습니다. 모두 압축 풀기 후 다시 실행 |
| "오프라인 팩이 완전하지 않습니다. 빠진 항목: …" | 복사 중 파일이 끊겼습니다. `offline\MANIFEST.txt` 의 크기와 비교하거나 팩을 다시 복사 |
| 파이썬 설치 실패 | 64비트 윈도우 10 이상인지 확인. 회사 보안 정책으로 설치가 막힌 PC일 수 있음 |
| "NVIDIA GPU가 보이지만 … CUDA 버전으로는 쓸 수 없습니다" | 그래픽 드라이버가 오래됨. NVIDIA 드라이버 업데이트(이것만 인터넷이 필요) 후 다시 실행하면 GPU 사용. 그때까지 CPU로 동작 |
| 팩 만들기 중 PyTorch 받기 실패 | 사내망이 `download.pytorch.org` 를 막았을 수 있음. 다른 네트워크에서 만들기 |

## 알아둘 점

- 팩은 **윈도우 64비트 + 파이썬 3.11** 전용입니다. 맥용 오프라인 팩은 아직 없습니다.
- 용량이 커서 GitHub Actions(자동 릴리스)에서는 만들지 않습니다. 새 버전을 낼 때는 인터넷 되는 PC에서 위 명령을 다시 실행하세요.
- 앱 코드만 바뀌고 모델·라이브러리가 그대로인 업데이트는, 기존 설치 위에 새 `Setup.exe` 또는 새 `app` 폴더를 덮어쓰는 것이 훨씬 가볍습니다.
- 설치 도우미는 `setup_windows.py --offline-dir <팩의 offline 폴더>` 로도 직접 실행할 수 있습니다.
