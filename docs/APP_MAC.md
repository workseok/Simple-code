# BG Matte 앱 (macOS) 사용 가이드

기존 `realtime_matte.py`(`cv2.imshow` 미리보기)를 대신하는 GUI 앱입니다. 개인 Mac에서만 쓰는 것을
전제로 하므로 서명·공증(notarization)은 하지 않습니다. 기존 CLI 스크립트는 그대로 남아 있습니다.

## 1. 설치와 .app 만들기

```bash
conda activate bgmatte                   # 기존 환경 (torch, opencv 설치된 환경)
pip install -r requirements-app.txt      # PySide6, pyobjc(카메라 권한 확인용) — 최초 1회
bash packaging/build_app.sh              # → dist/BG Matte.app
bash packaging/build_app.sh --install    # 위 + ~/Applications 에 복사
```

- 만들어진 앱은 **파이썬/라이브러리를 복사하지 않습니다.** 지금 켜 둔 conda 환경의 python과 이 저장소
  폴더를 가리키는 작은 런처입니다. 코드를 고치면 재빌드 없이 반영됩니다.
- 저장소 폴더나 conda 환경 이름/위치를 바꾸면 `build_app.sh`를 다시 실행하세요.
- 재빌드하면 앱 서명이 바뀌어 카메라 권한 팝업이 다시 뜰 수 있습니다.

## 2. 처음 실행 전 확인 (권장)

앱을 만들기 전에 터미널에서 각 단계를 먼저 점검하면 문제 위치를 바로 알 수 있습니다.

```bash
python -m bgmatte_app.selfcheck
```

카메라 권한, 배경 이미지, `bgr.png`, 모델 로드, 1프레임 추론과 예상 FPS를 차례로 확인합니다.
Intel Mac은 GPU 가속이 없어 CPU로 동작하므로 FPS가 낮을 수 있습니다. 설정에서 백본을 `resnet101` →
`resnet50` 또는 `mobilenetv2`로 낮추면 빨라집니다. 설정 창에는 백본마다 가중치 칸이 따로 있어서(`models/pytorch_resnet50.pth`, `pytorch_resnet101.pth`, `pytorch_mobilenetv2.pth`) 여러 파일을 함께 두고 '백본'만 바꿔 쓸 수 있습니다. 선택한 백본의 칸에 있는 파일만 사용합니다.

## 3. 첫 실행

1. `BG Matte.app` 더블클릭 → 카메라 권한 팝업 → **허용**
2. 팝업이 없고 화면이 검다면: 시스템 설정 → 개인정보 보호 및 보안 → 카메라 → `BG Matte` 켜기
3. 첫 실행에는 사용 안내 창이 열립니다. 이후에는 `H` 키로 다시 볼 수 있습니다.
4. `bgr.png`(피사체가 없는 빈 배경)가 없으면 **배경 촬영** 버튼 또는 스페이스바로 앱 안에서 촬영합니다.
   카운트다운 동안 화면 밖으로 비켜 주세요. 이전 `bgr.png`는 `bgr.prev.png`로 백업됩니다.
5. 촬영이 끝나면 자동으로 합성이 시작됩니다.

카메라는 촬영 시작부터 끝까지 **완전 고정**이어야 합니다. 조금이라도 움직이면 `bgr.png`를 다시 촬영하세요.

## 4. 합성 배경과 번호

`backgrounds/` 폴더에 이미지를 넣으면 이름순(자연 정렬: `bg2` < `bg10`)으로 **1번부터** 번호가 붙습니다.
화면 오른쪽 "합성 배경"에 번호 버튼과 현재 선택된 파일 이름이 표시됩니다.
폴더가 비어 있으면 기존 `ai_background.png`를 1번으로 사용합니다.
마지막으로 선택한 번호는 다음 실행 때 기억합니다.
번호 버튼은 9개이고 방향키 전환은 없으므로, 배경은 **9개 이하**로 두세요(10번째부터는 선택할 수 없습니다).

## 5. 단축키

| 키 | 동작 |
| --- | --- |
| `1`–`9` | 배경 번호로 바로 전환 |
| `Space` (스페이스바) | 빈 배경 촬영 (촬영 중에는 취소) |
| `A` | 알파 매트 함께 보기 |
| `F` | 전체 화면 |
| `H` | 사용 안내 |
| `Esc` | 촬영 취소 · 전체 화면 해제 · 종료 |
| `⌘ ,` | 설정 |

## 6. 상태와 안내 메시지

상단 단계 표시줄(카메라 → 배경 → 모델 → 합성)이 현재 진행 단계를 보여 주고, 문제가 생기면 미리보기 위
배너에 **무엇이 문제인지 / 어떻게 하면 되는지 / 바로 가기 버튼**을 함께 보여 줍니다. 지난 알림은
오른쪽 "알림 기록"에 남습니다.

## 7. 문제 해결

| 증상 | 확인 |
| --- | --- |
| 앱이 열리자마자 닫힘 | 오류 창에 나온 안내 확인, 로그 `~/Library/Logs/BGMatte/app.log` |
| "Python을 찾을 수 없습니다" | conda 환경을 켜고 `build_app.sh` 재실행 |
| 카메라 화면이 검음 | 위 3-2 권한 확인, 설정에서 카메라 번호 변경(캡처카드는 1 이상일 수 있음) |
| 모델/체크포인트 오류 | 설정에서 `BackgroundMattingV2` 폴더와 `.pth` 경로 지정 (기본값은 `docs/SETUP_MAC.md` 구조 기준) |
| 합성이 너무 느림 | 백본 낮추기, 카메라 해상도 낮추기, 또는 설정의 매팅 엔진 변경(`docs/ENGINES.md`) |
| 빈 배경 촬영 없이 쓰고 싶음 | 설정 → 매팅 엔진에서 MODNet 또는 RobustVideoMatting 선택 (`docs/ENGINES.md`, 설치: `bash packaging/install_engines.sh`) |
| 설정을 초기화하고 싶음 | `~/Library/Application Support/BGMatte/config.json` 삭제 |

## 8. 대체 실행 방법

- `.app`이 문제를 일으키면 `packaging/BGMatte.command`를 더블클릭하거나(최초 1회 `chmod +x`),
  터미널에서 `python -m bgmatte_app`을 실행하세요. 이 경우 카메라 권한은 터미널 앱에 붙습니다.

## 9. 화면 구성과 색

- 영상 테두리가 카메라의 탤리 램프처럼 상태를 알려줍니다: **초록 = 합성 중**, **빨강 = 촬영 중/오류**, **노랑 = 촬영 필요**, **파랑 = 준비 중**.
- 단축키 칩 색: 보라 = 배경 번호, 분홍 = 촬영, 청록 = 보기(알파·전체 화면·안내), 노랑 = 종료.
- 번호 버튼은 번호마다 아래쪽 색이 다르고, 지금 쓰는 번호만 초록으로 켜집니다.
- 앱 아이콘: `packaging/make_icon.py`로 다시 만들 수 있습니다. 아이콘을 바꾼 뒤에는 `bash packaging/build_app.sh --install`을 다시 실행해야 Finder 아이콘에 반영됩니다.

## 10. 화면 색상 (어둡게 / 밝게)

오른쪽 위 **어둡게 | 밝게** 버튼으로 바꿉니다. 선택은 저장되어 다음 실행에도 유지됩니다.
영상 미리보기 주변은 색을 정확히 보기 위해 두 모드 모두 검정입니다.
